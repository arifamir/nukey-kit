# nukey-kit

Open-source extensions for Claude Code, starring **Nukey the microwave**, packaged as a [plugin marketplace](https://code.claude.com/docs/en/plugin-marketplaces).

![nukey: Nukey the microwave above the prompt acts out what Claude is doing](plugins/nukey/assets/demo-scenes.svg)

## Install

In Claude Code:

```bash
claude plugin marketplace add arifamir/nukey-kit
claude plugin install nukey@nukey-kit
```

To receive updates automatically, open `/plugin`, select **Marketplaces** → `nukey-kit` → **Enable auto-update**.

## Plugins

| Plugin | What it does |
| :- | :- |
| [`nukey`](plugins/nukey) | Mod: Nukey the microwave sits above the prompt and acts out what Claude is doing, with a control-panel meter for context and rate limits and five colour themes |
